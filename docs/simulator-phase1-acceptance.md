# INVESTLAB 시뮬레이터 1단계 사용자 검증 (Draft PR #34)

> 범위: `virtual-trade-simulator.html` / 개발 브랜치 `feature/simulator-shared-symbols-20261111`.
> **운영 대시보드·Supabase·실제 매매원장 변경 금지. PR 병합 전 검증용.**

## 접근 및 데이터 출처

1. 개발 브랜치에서 시뮬레이터 HTML을 **동일 출처(origin)** 로 제공하는 미리보기에서 엽니다. 로컬 파일(`file://`)이나 운영 배포 페이지에서 열지 않습니다.
2. 종목관리 데이터는 브라우저의 `localStorage` (`investlab_holdings`, `investlab_watchlist`, `investlab_past_symbols`)를 읽기 전용으로 조회합니다. 다른 도메인·다른 브라우저·다른 기기에서는 같은 데이터를 자동으로 가져오지 못합니다.
3. **USD-CASH** 항목이 없으면 시작 현금을 수동 입력합니다. `USD` 항목은 자동 현금으로 간주하지 않습니다.
4. 최종 가정 주가는 실시간 시세가 아닙니다. 비어 있는 종목은 직접 입력해야 계산할 수 있습니다.

## 수동 검증 절차

- [ ] 원본 보유종목의 종목코드, 수량, 평균 취득단가가 정확히 불러와지는지 확인
- [ ] 보유·관심·거래이력 종목 선택 후보가 현재 브라우저의 종목관리 데이터와 일치하는지 확인
- [ ] 기존 종목 가격이 없을 때 빈칸과 안내가 표시되고, 직접 입력 후 계산되는지 확인
- [ ] TSLA 10주, 평균단가 $100, 시작 현금 $100, TSLA 최종가 $150 입력
- [ ] 가상 매도: TSLA 2주 × $200, 수수료 $0
- [ ] 가상 매수: SOXL 10주 × $30, 수수료 $0. 신규 SOXL 최종가 $40 입력
- [ ] 최종 수량: TSLA 8주, SOXL 10주; 현금 $200
- [ ] 보유 유지 평가액 $1,600, 가상 평가액 $1,800, 차이 +$200 확인
- [ ] TSLA 999주 매도 시 입력 오류가 표시되고 성공 메시지가 남지 않는지 확인
- [ ] 원본 포트폴리오·관심종목·거래이력 데이터가 변경되지 않는지 확인
- [ ] 실제 사용자 보유 종목과 금액으로 다시 시험하고 결과 스크린샷을 남김

## 자동화 상태 및 미완료 게이트

- 시뮬레이터 전용 단위/Chromium 브라우저 테스트: GitHub Actions `Simulator unit tests`의 **최신 커밋 성공 여부**를 확인해야 합니다.
- 전체 `Validate dashboard scripts`는 별도 검증 작업입니다. 공유 데이터 TEST Supabase 및 기존 페이지 관련 실패가 있어 별도 조사 대상입니다.
- 미리보기 주소, 동일 출처 종목관리 데이터, 실제 사용자 계정의 브라우저 환경은 자동 테스트로 확인되지 않았습니다.
- 운영 Supabase 쓰기, PR 병합, 운영 배포는 승인 전 수행하지 않습니다.
