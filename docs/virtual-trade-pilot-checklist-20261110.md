## 실행 환경
- 브랜치: `feature/shared-data-import-preflight-20261108`
- 페이지: `http://localhost:8000/virtual-trade-simulator.html`
- 필수 상대 경로: `src/simulator/scenario-comparison.mjs`, `src/simulator/overseas-stock-tax.mjs`
- 실제 투자원장·운영 Supabase·TEST Supabase를 변경하지 않음
- 회사 환경에서 GitHub 다운로드가 제한되면 파일 내용 복사 후 UTF-8 HTML로 저장하되, 기존 파일은 백업

## A. 기본 시나리오 — 사용자가 화면으로 확인한 값
시작 현금 $1,000 / TSLA 10주(평균 $100) / 최종 TSLA $150
- [x] 화면에서 두 전략 및 보유종목 입력창이 표시됨 (2026-11-10 스크린샷)
- [x] 기본 계산: 계속 보유 $2,500
- [x] 상승장 단계별 매도: 현금 $2,020 / 평가총액 $2,770 / 실현손익 $520
- [x] 하락장 재매수: 현금 $1,000 / 평가총액 $3,250 / 실현손익 $500
- [x] 세금 시험값으로 상승장 추가 세액 286,000원, 하락장 110,000원 표시
- [ ] 수량·가격을 변경하고 재계산했을 때 결과가 즉시 갱신되는지 확인

## B. 일반 입력창 — 아직 미검증
- [ ] 시작 현금·보유종목·최종가격 변경 및 추가/삭제
- [ ] 전략 추가/삭제 및 거래 추가/삭제
- [ ] 전략 이름 수정 후 세금 입력이 올바른 전략과 연결되는지 확인
- [ ] 전략별 매도 건수와 세금용 원화 손익 입력칸 수 일치
- [ ] '세금 계산 예시 입력' → '시나리오 계산' → 세액 출력
- [ ] 손익 일부 미입력 시 오류 메시지 표시

- [ ] 고급 JSON 입력을 일반 입력창에 반영
