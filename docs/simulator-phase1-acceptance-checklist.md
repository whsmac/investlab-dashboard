# 시뮬레이터 1단계 사용자 검증 체크리스트 (Draft)

> 이 문서는 PR #34 개발 브랜치의 `virtual-trade-simulator.html` 검증용입니다. 운영 데이터베이스 변경, 실제 주문, PR 병합을 요구하지 않습니다.

## 검증 전제

- 기존 대시보드에서 보유·관심·거래이력 종목을 관리합니다.
- 시뮬레이터는 브라우저의 `investlab_holdings`, `investlab_watchlist`, `investlab_past_symbols` 데이터를 읽습니다. 동일 브라우저/동일 출처(origin)의 저장소가 아니면 자동으로 공유되지 않습니다.
- 보유 수량과 평균 매입단가는 실제 입력값을 사용하고, **최종 가정주가**는 별도로 입력합니다.
- USD 현금은 명시적으로 관리된 `USD-CASH` 값만 자동 반영합니다. 없으면 사용자가 직접 확인·입력합니다.
- 실거래·Supabase 쓰기 기능이 아닙니다.

## 사용자 수동 확인 (미리보기 배포 후)

1. 실제 보유종목을 불러왔을 때 종목코드·수량·평균단가가 일치하는지 확인합니다.
2. 관심종목 및 거래이력 종목이 종목코드 입력 제안에 표시되는지 확인합니다.
3. 최종 가정주가가 없는 종목은 임의 가격으로 채우지 않고 빈칸으로 표시되는지 확인합니다.
4. 현재 현금잔액을 확인하고 필요하면 입력합니다.
5. TSLA 일부 매도 → SOXL 매수 등의 가상 거래를 입력합니다. 새 종목의 최종 가정주가 입력란이 생성되는지 확인합니다.
6. 매수·매도 수량, 최종 현금, 기준 평가액, 가상 평가액, 차액을 비교합니다.
7. 보유량 초과 매도를 입력하면 성공 메시지나 과거 계산 결과가 남지 않는지 확인합니다.
8. 원래 대시보드의 보유·관심·거래이력 데이터가 바뀌지 않았는지 확인합니다.

## 자동 검증 범위

- `tests/simulator-browser-smoke.mjs`: 실제 형식의 보유/현금 불러오기, 관심종목 제안, 가격 누락, 매도·매수, 평가액, 초과매도, 원본 저장소 불변, Supabase 요청 차단.
- `.github/workflows/simulator-tests.yml`: 브라우저 테스트 및 시뮬레이터 전용 단위 테스트.

## 현재 제한사항

- 사용자 실데이터를 사용한 수동 검증은 아직 수행하지 않았습니다.
- 전체 대시보드 검증 워크플로는 시뮬레이터 전용 워크플로와 별개이며, 공유 데이터 관련 실패를 별도 추적합니다.
- 미리보기 URL은 실제 배포를 확인한 뒤 제공해야 합니다.

## 재현 가능한 기준값 (실제 보유자료 아님)

| 항목 | 값 |
| --- | --- |
| 시작 보유 | TSLA 10주, 평균단가 $100 |
| 시작 현금 | $100 |
| TSLA 최종 가정주가 | $150 |
| 가상 거래 1 | TSLA 2주를 주당 $200에 매도 |
| 가상 거래 2 | SOXL 10주를 주당 $30에 매수 |
| SOXL 최종 가정주가 | $40 |
| 거래 수수료 | $0 |

**기대 결과:** TSLA 8주, SOXL 10주, 최종 현금 $200, 계속 보유 평가액 $1,600, 가상 거래 평가액 $1,800, 보유 대비 +$200. 신규 SOXL 가격을 입력하기 전에는 계산 완료 메시지가 표시되지 않아야 합니다.

**검수 주의:** 수동 테스트를 위해 운영 보유 데이터를 덮어쓰지 마세요. 위 기준값은 독립 테스트 브라우저/프로필이나 자동화 테스트에서만 사용합니다.
