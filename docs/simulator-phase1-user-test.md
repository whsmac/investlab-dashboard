# INVESTLAB 1단계 가상 매매 시뮬레이터 — 사용자 테스트

> 범위: PR #34 Draft의 독립 테스트 화면. 운영 대시보드·운영 Supabase·기존 보유/관심종목 데이터는 수정하지 않습니다.

## 실행 환경

1. GitHub에서 `feature/simulator-shared-symbols-20261111` 브랜치를 ZIP으로 내려받아 압축을 해제합니다.
2. Mac 터미널에서 압축 해제한 폴더로 이동해 `python3 -m http.server 8765`를 실행합니다.
3. 브라우저에서 `http://localhost:8765/virtual-trade-simulator.html`을 엽니다.
4. 이 독립 화면은 현재 브라우저의 `localStorage`에 있는 `investlab_holdings`, `investlab_watchlist`, `investlab_past_symbols`만 읽습니다. 기존 대시보드를 다른 주소에서 사용했다면 **브라우저 저장공간이 분리되므로 자동 공유되지 않습니다**. 없는 데이터를 임의로 생성하지 않습니다.

## 실사용 확인

- 보유종목과 현금이 보이면 원본 수량·평균단가·현금이 맞는지 확인합니다.
- 보유종목에 가격이 없으면 최종 가정주가를 직접 입력합니다. 평균단가를 현재가로 대체하지 않습니다.
- 전략에서 보유종목 일부를 매도하고, 관심종목을 신규 매수한 다음 새 종목의 최종 가정주가를 입력합니다.
- '계산' 후 최종 현금, 보유 수량, 전체 평가총액, 계속 보유 대비 차이를 비교합니다.
- 보유 수량보다 많은 수량을 매도해 오류가 표시되고 이전 성공 결과가 지워지는지 확인합니다.
- 테스트 전후 실제 대시보드의 보유·관심종목 데이터가 그대로인지 확인합니다.

시작 TSLA 10주(가정주가 $150), 현금 $100 → TSLA 2주를 $200에 매도 → SOXL 10주를 $30에 매수 → SOXL 최종 가정주가 $40. 수수료 $0 가정.

| 지표 | 계속 보유 | 가상 매매 |
| --- | ---: | ---: |
| TSLA | 10주 | 8주 |
| SOXL | 0주 | 10주 |
| 현금 | $100 | $200 |
| 최종 평가총액 | $1,600 | $1,800 |

## 제한 사항

- 본 화면은 테스트용 독립 HTML이며 실제 주문·계좌 변경·Supabase 저장을 하지 않습니다.
- 현재 Vercel의 기존 `investlab-phase1-preview` 배포는 이 PR #34 브랜치가 배포되었다는 근거가 없으므로 이 테스트의 미리보기 주소로 사용하지 않습니다.
- 서로 다른 출처(origin)의 브라우저 저장소는 자동으로 공유되지 않습니다. 실제 보유 데이터가 나타나지 않는 경우 원본 계좌 정보가 삭제된 것은 아닙니다.
- PR 병합 및 운영 Supabase 변경은 별도 승인 전까지 금지합니다.
