# INVESTLAB 시뮬레이터 1단계 사용자 검증

대상: Draft PR #34의 virtual-trade-simulator.html. 운영 반영 및 병합 금지.

## 사용자 확인 순서
1. 원본 포트폴리오의 보유·관심·거래이력 종목을 확인한다.
2. 같은 브라우저 주소(origin)에서 시뮬레이터를 열어 보유종목과 USD-CASH를 불러온다. 다른 주소는 localStorage를 공유하지 않는다.
3. 주가가 누락된 보유종목은 빈 최종 가정주가 입력칸으로 표시되는지 확인한다.
4. 시작 현금과 종목별 최종 가정주가를 입력한다.
5. TSLA 2주 × $200 매도, SOXL 10주 × $30 매수를 입력한다.
6. SOXL 최종 가정주가 $40을 입력한 뒤 다시 계산한다.
7. TSLA 매도 수량을 보유량보다 큰 999주로 바꿔 계산하고, 오류 안내가 나오며 직전 성공 결과가 지워지는지 확인한다. 이후 2주로 되돌린다.
8. 원본 포트폴리오의 보유수량·평균단가·거래이력과 관심종목 목록이 변경되지 않았는지 확인한다.

## 독립 예시의 기대 결과
시작: TSLA 10주, TSLA 최종가격 $150, 현금 $100, 수수료 $0.
보유 유지 평가액 $1,600. 가상 거래 후 TSLA 8주, SOXL 10주, 현금 $200, 평가액 $1,800. 차이 +$200.
이는 실제 사용자 계좌의 값이 아니라 가상 테스트 수치다.

## 안전 범위
- 원본 investlab_holdings 읽기 전용. 실제 거래나 Supabase 저장 없음.
- 현금 자동 읽기는 명시적 USD-CASH만 지원.
- 원본과 다른 origin의 미리보기에서는 localStorage 자동 연동 불가.
- 환율·세금은 별도 조건 확인 필요. USD 실현손익 자동 KRW 환산 없음.
- Simulator unit tests 통과와 전체 Validate dashboard scripts 통과는 별개.
- 사용자 승인 전 PR 병합·운영 Supabase 변경·운영 대시보드 교체 금지.
