# INVESTLAB 핵심 기능: 가상 매수·매도 및 양도세 시뮬레이션

상태: 요구사항 확정 기록 복원 / 구현 우선순위 최상위 / 실제 거래원장과 분리

## 목적
실제 보유종목을 선택해 가상의 체결가격·수량·수수료·환율을 입력하고, 거래 전후 보유량과 현금, 예상 실현손익, 해외주식 양도소득세 및 세후 수익을 미리 비교한다. **가상 거래는 실제 원장에 절대 저장하지 않는다.**

## 다른 프로젝트 대화에서 확인한 기존 합의
- 거래원장 우선: 매수·매도·입출금·배당·환전·잔고, 정정·삭제 및 이력 보존
- 매수 수수료는 취득원가에 포함; 매도 수수료는 매도대금에서 차감
- 가중평균 취득원가 및 실현손익을 원장 계산과 일관되게 적용
- 원장 환율과 세금용 환율은 별도로 취급
- 세금 계산은 원장과 분리된 모듈; 운영 데이터 변경·병합은 명시적 승인 전 금지

## 우선 개발 순서
1. **독립형 시뮬레이션 계산 엔진과 테스트**: 실거래 저장 없이 가상 매수·매도 계산
2. **보유종목 연동 UI**: 원장 포지션을 읽기 전용으로 불러오고 가상 거래 입력
3. **세금 추정 엔진**: 원화 환산 취득·양도가액, 매매 수수료, 해당 과세연도 기실현 해외주식 손익, 기본공제 적용 상태, 세율을 구분
4. **시나리오 비교**: 여러 가격·수량·환율 가정의 세전·세후 결과 비교
5. **통합 및 검증**: 원장 불변성, 경계조건, 환율·세법 연도별 규칙 검증

## 계산 및 세무 안전 원칙
- 매도 시 수량이 실제 보유수량을 넘지 않도록 한다(공매도 기능 제외).
- 매수 시 현금 부족 여부를 표시하되 가상 현금을 실제로 차감하지 않는다.
- 가상 매도 손익은 평균원가 방식의 **원장용 추정치**와 세법상 원화 기준 **과세 추정치**를 별도 표시한다. 두 수치는 일치한다고 가정하지 않는다.
- 해외주식 양도세는 거래일·취득일의 세금용 원화 환율, 연간 다른 양도손익, 공제 사용액 및 과세연도 규칙에 따라 달라진다. 자료가 없으면 세액을 확정 표시하지 않는다.
- 기본공제 250만원 및 세율 22%는 국내 거주 개인의 일반적인 해외주식 양도세 시뮬레이션 기본값 후보일 뿐, 실제 구현 시 과세연도와 개인별 적용요건을 검증하고 수정 가능하게 둔다.
- 가상 거래는 브라우저 계산 상태로만 취급한다. `ledger_transactions` 또는 실제 Supabase 거래 테이블에 insert/update/delete 하지 않는다.
- 운영 DB 및 TEST DB 모두에 이 모듈로 인한 스키마 변경을 요구하지 않는다.

## 완료 기준
- 동일 입력에서 재현 가능한 결과와 자동 테스트
- 수수료·보유수량·평균원가·환율 경계조건 검증
- 실원장 읽기와 가상 시뮬레이션의 쓰기 권한 분리
- 세전 수익, 세금 추정치, 세후 수익을 명확하게 구분
- 사용자가 지정한 여러 가상 매도/매수 가격을 즉시 재계산
