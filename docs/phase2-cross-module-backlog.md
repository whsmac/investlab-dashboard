# INVESTLAB — 모듈별 2단계 개선 아이디어 통합 백로그

작성: 2026-11-11
상태: **계획/아이디어 정리**. 구현 완료를 의미하지 않음. 기존 대시보드·운영 Supabase 수정, PR 병합은 별도 승인 필요.

## 운영 원칙
- 개발 중 사용자가 언급한 개선의견을 **모듈별로 누적 기록**한다. 새로운 아이디어는 기존 항목을 지우지 않고 출처·결정 상태를 갱신한다.
- 상태 구분: **확정 요구** / **검토 아이디어** / **검증 필요** / **보류** / **구현·테스트 완료**. 코드 존재와 실제 환경 검증은 구분한다.
- 1단계 기능 구현 및 사용자 검증을 우선하고, 2단계는 승인 후 착수한다.
- 원본 My Portfolio 및 거래원장 보존, TEST/운영 Supabase 분리, Draft PR 미병합 원칙 준수.
- 무료·합법적으로 이용 가능한 공개 데이터 우선; 유료 API/구독 및 약관 우회 수집 제외. 결측은 숨기지 않는다.

## 1. 가상 매매 시뮬레이터
- **확정 요구 / 2단계:** TSLA 등 1배 주식 단계적 매도 → 현금 확보 → SOXL·TQQQ 목표가별 단계적 매수 → 반등 목표가별 단계적 매도 → TSLA 등 1배 주식 재매수.
- 목표가격·거래수량·순서 설정, 거래 단계별 현금 검증, 이름별 시나리오 저장·수정·복제·비교.
- 종목별 초기/최종 수량, 현금, 평가총액, 실현손익, 추정 양도세, 세후 자산, 계속 보유 대비 차이.
- **합의된 가정:** 레버리지 ETF는 단기 거래; 장기 변동성 손실 분석 제외. 반등 시 ETF 상승률이 TSLA보다 높다는 기본 가정; 역전은 예외. 설정 목표가에 체결된 것으로 가정.
- 상세 문서: [virtual-trade-phase2-plan.md](./virtual-trade-phase2-plan.md).
- **1단계와 분리:** 초기 포트폴리오 불러오기, 단순 가상 매매, 최종 보유·평가총액, 전후 비교를 먼저 검증.

## 2. 종목 관리·포트폴리오
- **확정 요구:** 보유/관심/과거 거래 종목의 단일 원본을 다른 모듈에서 재사용; 각 화면에 중복 등록하지 않음.
- **검증 필요:** 브라우저/도메인/기기별 저장소 차이와 목록 동기화, 동일 종목 중복 제거, USD 현금 항목과 일반 주식 구분.
- **검토 아이디어:** 포트폴리오 평가금액·기준 주가·현금과 거래원장 계산 결과의 일관성 점검; 데이터 이동 시 충돌 해결.

## 3. 매매기록장·현금·환율
- **확정 요구:** 매매일, 종목, 수량, 체결가, 수수료, 실현손익과 현금 변동을 일관되게 기록; 천 단위 쉼표 입력; 종목은 기존 종목관리에서 선택; 적용환율은 선택 방식 지원.
- **검증 필요:** 적용환율 입력/선택 및 원화 환산 결과, 매매기록과 현금잔액의 정합성, 초기 보유정보 이관·대사.
- **후속 개선:** 거래 편집 시 종목·계좌·거래일 변경 지원(현 파일에 후속 단계로 명시); 현재가 연결; Supabase 동기화/이력 및 재계산 규칙.
- **보류:** 실제 원장 또는 운영 DB 변경은 별도 승인 전 금지.

## 4. 세금·성과 분석
- **2단계 검토:** 과세계좌 구분, 원화 취득·양도금액, 거래별 적용환율, 연도별 실현손익·공제, 추정 해외주식 양도세; 세전/세후 전략 비교.
- **검증 필요:** 세금 기준연도, 다른 계좌 실현손익 합산, 계산 가정과 실제 신고세액의 차이.
- **성과 분석 아이디어:** 기간별 수익률, 거래 효과와 주가 효과 분리, 기준 전략(계속 보유) 대비 성과.

## 5. 주가·기업 재무·AI 투자 분석
- **기존 방향:** MSFT, GOOGL, AMZN, META, TSLA, SPCX의 일별 주가 및 분기 매출/CAPEX 비교; 주가 기준일 100 비교, 분기 추세.
- **2단계 아이디어:** 하이퍼스케일러 CAPEX 추세와 클라우드/AI 사업 매출·수익성 연계, 투자 사이클 경고, CAPEX 대비 성과·종합 의사결정 지표.
- **검증 필요:** SEC XBRL 항목 매핑, 누적 보고값의 분기 환산, 재무 데이터 결측·오류, 주가 데이터 출처/사용권.
- **주의:** SPCX 비상장으로 주가·재무 데이터가 없으면 가상 값을 생성하지 않고 결측으로 표시. 무료 공개 데이터 정책 유지.

## 6. 공유 데이터·Supabase·CSV
- **기존 보류/검증 필요:** PR #33 Draft의 오프라인 CSV 검증, 인증된 dry-run, 원자적 import RPC 초안과 TEST 실제 권한·롤백·중복 검증의 구분.
- **후속:** 브라우저 업로드 UI 연동, 사전검증 결과 표시, 명시적 승인 후 TEST RPC 설치·쓰기 검증, 운영 이관 전 별도 승인.
- **안전 게이트:** 서비스 역할 키 노출 금지, 운영 프로젝트 격리, 데이터 쓰기 전 dry-run과 롤백 검증.

## 7. 대시보드 통합·운영 안정성
- **확정 방향:** 최종 기능은 별도 신규 대시보드보다 기존 INVESTLAB 대시보드에 통합하되 운영 환경은 승인 전 불변.
- **후속:** 종목관리 → 거래원장 → 통합 가격/성과 차트 → 대시보드 통합 → 안정성 검증 순서와 의존성 재확인.
- **검증 필요:** PC/모바일/다른 브라우저 간 데이터 일관성, 로컬 저장과 클라우드 동기화, CSV 오류 안내, 접근 환경별 화면 테스트.
