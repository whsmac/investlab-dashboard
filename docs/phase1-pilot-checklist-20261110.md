# INVESTLAB 1차 Pilot Test 점검표 (2026-11-10)

## 현재 범위
- 브라우저 단독 가상 거래 시뮬레이터: 시작 현금·보유종목·최종 가정 가격·전략별 다단계 거래
- USD 매매/평가와 사용자 별도 입력 KRW 세액 추정
- 공유 데이터 조회 및 TEST CSV 가져오기
- 기존 대시보드 연결용 탐색 링크

## Pilot Test 절차
| 번호 | 화면/모듈 | 입력 또는 동작 | 기대 결과 |
|---|---|---|---|
| 1 | 시뮬레이터 | 기본 TSLA 10주, 현금 1000, 최종 주가 150 | 계속 보유 평가총액 2500 USD |
| 2 | 상승장 단계별 매도 | TSLA 2주 × 180, 3주 × 220 | 현금 2020, 보유 5주, 평가총액 2770 USD, 실현손익 520 USD |
| 3 | 하락장 재매수 | TSLA 5주 × 200 매도, 10주 × 100 매수 | 현금 1000, 보유 15주, 평가총액 3250 USD, 실현손익 500 USD |
| 4 | 세금 예시 | 기존 원화 실현손익 300만, 전략별 예시 50만/80만 | 1번 전략 추가 세액 286000 KRW, 2번 110000 KRW. 시험값임을 표시 |
| 5 | 입력 검증 | 시작 현금에 음수, 거래 수량에 음수 입력 | 오류 메시지 표시, 잘못된 결과를 정상값처럼 표시하지 않음 |
| 6 | 입력 검증 | 보유종목/가정 주가 종목명 중복 | 중복 입력 오류 |
| 7 | 전략 편집 | 매수·매도 거래 추가·삭제, 가격 변경 | 변경된 조건으로 재계산 |
| 8 | 안전성 | 시뮬레이터 계산 | 실제 원장·Supabase 저장 없음 |
| 9 | 공유 데이터 | 공유 조회 페이지 열기 | 기존 TEST 자료 조회, 결측·출처는 실제 상태대로 표시 |
| 10 | 탐색 | 대시보드·공유 데이터 링크 | 해당 로컬 페이지로 이동 |

## 현재 확인 상태
- 사용자 브라우저 스크린샷으로 1~4번 계산/표시 확인 (2026-11-10).
- 5~10번은 새 코드에 대한 브라우저 Pilot Test 미확인.
- 2026-11-10 숫자 입력 검증 및 종목 표시폭 수정은 GitHub 반영, 브라우저 확인 전.
- 세금은 매도 시점 환율·실제 세무 취득원가 미반영. 실제 세액이 아닌 사용자 입력 KRW 손익의 가정 계산.
- 테스트용 주가 CSV는 외부 원본 검증이 완료되지 않은 자료.

## 버그·개선 접수 형식
모듈 / 재현 절차 / 기대 결과 / 실제 결과 / 심각도(차단·불편·개선) / 1차 수정 또는 후속 개발

## 1차 완료 전 반드시 해결
- 실행을 막는 HTML/JS 구문 오류
- 현금·수량·손익·세금의 핵심 계산 오류
- 실거래 또는 운영 DB에 의도치 않은 영향

## 후속 개발 후보
- 세금 입력의 JSON 제거 및 거래별 취득원가/환율 지원
- 정교한 세법 적용 및 유료 데이터/원본 대조
- 자동 수집 파이프라인과 고급 AI 투자분석
